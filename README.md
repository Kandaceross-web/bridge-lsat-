# Bridge LSAT

A personal LSAT study app: the Argument Foundations unit (Step 1: Conclusion), a 142-word vocabulary system with spaced repetition, a one-year study plan, and test readiness tracking.

Live site: https://kandaceross-web.github.io/bridge-lsat-/

- This web version works in any browser with no sign-in. Progress is saved in the browser you use; move it between devices with the progress code in Settings.
- The live AI tutor only works in the Claude version of Bridge LSAT.
- All practice questions are original LSAT-style questions, not official LSAC material.
